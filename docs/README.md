# GitHub Profile README

A premium GitHub profile README for Aditya Sharma, featuring a cyberpunk theme with dynamic widgets, GitHub automation, and professional branding.

## Features

- Cyberpunk-themed design with neon glow effects
- Dynamic GitHub statistics and streaks
- Automatic blog post updates from Medium
- Snake animation for contribution graph
- Responsive design for all devices
- Easy to customize via config files

## Setup

1. Fork or clone this repository
2. Update `config/profile.json` with your details
3. Push to your GitHub account
4. Enable GitHub Actions in repository settings

## Customization

Edit `config/profile.json` to update:
- Personal information
- Social links
- Skills and technologies
- Theme colors

## GitHub Actions

- `snake.yml` - Generates contribution snake animation
- `blog-post.yml` - Updates blog posts from Medium RSS
- `stats.yml` - Updates GitHub statistics

## Required Secrets

No additional secrets required. Uses the default `GITHUB_TOKEN`.
